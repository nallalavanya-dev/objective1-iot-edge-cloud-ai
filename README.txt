OBJECTIVE 1 – EXISTING ANIMATED DASHBOARD + MULTI-NODE DATASET TRAINING

This version preserves the existing dashboard experience: custom task name, application presets, left-side task requirements, animated IoT network, regression algorithm comparison, task prediction graphs, delay component charts, residual diagnostics and AI deadline-aware node selection.

What changed only in the training/data integration:
- The previous in-code synthetic data generator has been removed from model training.
- The app now loads objective1_iot_multinode_training_dataset.csv located beside app.py.
- Nine regression algorithms train on the CSV rows marked train and are evaluated on rows marked test.
- The CSV split is grouped by task_id, so all six candidate node records for a task remain in the same partition.
- Six candidate execution locations are evaluated: Local Device, Edge Server 1, Edge Server 2, Edge Server 3, Edge Server 4 and Cloud Server.
- The left panel includes task name, application, task type, priority, input size, CPU cycles, output size, deadline, and each node's bandwidth, RTT, CPU capacity, utilization and queue length.
- task_name/task_id are display identifiers and are intentionally not model features. The model uses task/application type, priority, task requirements and node/network/resource state.
- The best regression model is selected by lowest RMSE on the held-out test split for this demonstration. For formal publication, reserve a validation set for model selection and keep a final untouched test set.

DATASET
- objective1_iot_multinode_training_dataset.csv: 72,000 rows, 12,000 task episodes × six nodes.
- objective1_task_decision_dataset.csv: 12,000 task-level wide records, included for analysis and further decision-model work.

RUN ON WINDOWS ANACONDA PROMPT
1. Extract the ZIP.
2. Open Anaconda Prompt.
3. Run:
   conda activate iot_obj1
   cd /d "PATH_TO_EXTRACTED_FOLDER\objective1_live_prediction_lab"
   python -m pip install -r requirements.txt
   python -m streamlit run app.py

Keep both CSV files in the same folder as app.py. First model training can take a few minutes. Streamlit caches the trained models for the session.

RESEARCH INTEGRITY
The CSV is a synthetic, physically inspired benchmark. Its completion-time target and recommended-node labels are generated by a simulation model, not real measurements. The app does not send real network packets or execute tasks remotely. Validate with independent NS-3/SimPy scenarios and measured ESP32/Wi-Fi/edge/cloud traces before reporting real-world performance.
